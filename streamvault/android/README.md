# StreamVault Sender (Android)

Приложение-передатчик: транслирует экран планшета (или камеру) и микрофон на сервер StreamVault.

## Как собрать
Откройте папку `android/` в Android Studio (Ladybug+), дождитесь синхронизации Gradle, `Run`.
APK: `Build → Build APK`. Нужны JDK 17 и Android SDK 35.

## Как пользоваться
1. В админке сервера создайте «ключ эфира» (имя, например `tablet1`) — ключ показывается один раз.
2. В приложении введите: сервер `rtmps://ваш-домен`, имя `tablet1`, ключ.
3. Выберите: Экран или Камера, микрофон, ориентация (горизонтально/вертикально — выбирается до старта).
4. «Начать эфир» → Android спросит разрешение на запись экрана → в статусе появится «В эфире».
5. Зрители видят эфир только в веб-панели после входа.

## Безопасность
- Настройки (в т.ч. ключ) хранятся в `EncryptedSharedPreferences` (Android Keystore); `FLAG_SECURE` запрещает скриншоты окна.
- Принимается только `rtmps://` (исключение — локальные адреса для теста).
- При отзыве ключа в админке эфир отключается/не стартует.
- Android всегда показывает уведомление и значок записи экрана — скрыть их нельзя.
