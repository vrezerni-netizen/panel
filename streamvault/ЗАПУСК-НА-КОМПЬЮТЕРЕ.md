# Ахмат Запад — запуск на компьютере (домашняя сеть)

Подходит любой компьютер: Windows 10/11, Linux или Mac. Нужен только **Node.js 22** (https://nodejs.org).

1. Скачайте проект (кнопка Code → Download ZIP на странице ветки) и распакуйте. Откройте папку `streamvault`.
2. **Windows:** дважды щёлкните `Запустить-Windows.bat` (или `start-windows.bat`). **Linux/Mac:** `./start.sh`.
3. При первом запуске введите логин и пароль (12+ символов) администратора. Откройте файл
   `data/VAZHNO-qr-dlya-authenticator.png`, отсканируйте QR в Google/Microsoft Authenticator и удалите файл.
4. Откроется панель (http://localhost:3000): вход по паролю и коду. В админке создайте «ключ эфира» (имя `tablet1`).
5. Планшет подключите к тому же Wi-Fi. В приложении «Ахмат Запад»: сервер `rtmp://адрес-компьютера`
   (адрес покажет окно запуска), имя `tablet1`, ключ → «Начать эфир».
6. Зрители в той же сети открывают `http://адрес-компьютера:3000`.

Windows может спросить про доступ в сеть — разрешите для «частных сетей».
Это режим для домашней сети: без шифрования и без записи. Для интернета нужен сервер с HTTPS (см. README.md).
