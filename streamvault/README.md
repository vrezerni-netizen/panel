# StreamVault (MVP)

Приватный сервер прямых эфиров: приём потока с Android → просмотр только после входа (логин + пароль + код Authenticator).

## Что готово (этап 1–2)
- Вход: пароль (scrypt) → TOTP-код (RFC 6238, защита от повтора кода) → сессия (HttpOnly, SameSite=Strict).
- Блокировка аккаунта после 5 неверных попыток, лимит запросов по IP, журнал событий.
- Регистрации нет: пользователей создаёт только админ (QR для Authenticator показывается один раз).
- Ключи эфира: создаются/отзываются в админке, в базе хранится только хэш.
- MediaMTX принимает RTMP/SRT, проверяя ключ через `/internal/mediamtx/auth`; HLS доступен только на localhost
  и отдаётся зрителям через прокси `/hls/...` — только с действующей сессией. YouTube не используется.

## Запуск
```
npm install
npm run create-admin -- admin 'длинный-пароль-12+'   # покажет QR для Authenticator
npm start                                            # 127.0.0.1:3000
# MediaMTX: deploy/mediamtx.yml; HTTPS: deploy/Caddyfile; всё вместе: deploy/docker-compose.yml
npm test
```
Публикация с планшета: `rtmp://СЕРВЕР/live/<имя>?user=pub&pass=<ключ>`.
