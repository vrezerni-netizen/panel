# 🌾 Весёлая ферма

Милая пиксельная игра-ферма в браузере. Работает на компьютере и на телефоне, без установки и без интернета.

## Как запустить
Откройте файл **`index.html`** двойным щелчком (в Chrome, Edge, Opera, Firefox, Safari). Больше ничего не нужно.
Хотите играть с телефона: выложите папку `farm-game` на любой хостинг сайтов (например, GitHub Pages) или откройте файл с телефона.

## Как играть
1. ⛏️ **Мотыга**: коснитесь травы, чтобы вскопать грядку (зажмите и ведите пальцем, чтобы вскопать сразу много клеток).
2. 🌱 **Посев**: выберите семена и коснитесь вскопанной земли.
3. 💧 **Лейка**: полейте растения, с водой они растут вдвое быстрее. Над сухим растением виден значок капли.
4. 🧺 **Сбор**: когда над растением блестит звёздочка, коснитесь его.
5. 🛒 **Магазин**: продавайте урожай, покупайте семена, удобрение 🧪, расширяйте участок и улучшайте лейку.
6. 🐔🐄 С 3 уровня курятник, с 5 уровня хлев: коснитесь постройки наверху, чтобы собрать яйца или молоко.

Игра сохраняется сама. Пока вас нет, растения растут (до 8 часов). Меняются день и ночь.
Клавиши: `1`–`6` инструменты, `S` магазин, `Esc` закрыть окно.

## Что внутри
- `logic.js`: правила игры (рост, магазин, животные, уровни). Проверяется автотестами: `node --test test/logic.test.js`.
- `game.js`: графика (пиксельные картинки рисуются кодом), ввод, звуки, интерфейс.
- `index.html`, `style.css`: страница и оформление.
