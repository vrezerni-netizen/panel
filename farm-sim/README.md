# Farm Sim (Unity) — новая версия игры

Полноценный 3D-симулятор фермы в духе Farming Simulator. Движок **Unity 6 (6000.0 LTS)**, рендер **URP**, язык **C#**.

Это не замена браузерной игре из `farm-game/`, а новый проект «с нуля». Он строится по шагам.

| Шаг | Система | Статус |
|---|---|---|
| 1 | Сетка полей: данные, шейдер грунта, проход орудия, рост, сохранение | ✅ код и тесты логики — [Docs/01-FieldGrid.md](Docs/01-FieldGrid.md) |
| 1б | Растения на полях: GPU-инстансинг с отбором в compute-шейдере | ✅ код и тест — [Docs/01b-Crops.md](Docs/01b-Crops.md) |
| 2 | Физика трактора, 3-точечная навеска, ВОМ | ⏳ |
| 3 | Орудия: плуг, культиватор, сеялка, комбайн | ⏳ (их работа с землёй уже есть в шаге 1) |
| 4 | Экономика, силосы, прицепы, продажа | ⏳ |
| 5 | Наёмный рабочий: челнок по полю | ⏳ |

## Как открыть

1. Установить **Unity Hub** и **Unity 6 LTS** с шаблоном **Universal 3D (URP)**.
2. Создать пустой URP-проект и скопировать в него папку `Assets/FarmSim`.
3. Как собрать сцену, описано в [Docs/01-FieldGrid.md](Docs/01-FieldGrid.md), раздел 6.

## Проверка без Unity

Тесты логики полей запускаются без Unity:

```
dotnet test Tools/FieldTests
```

Нужен .NET 8. Те же тесты есть в Unity: Test Runner → EditMode.

## Что проверено, а что нет

- **Проверено:** логика сетки полей и индекса растений (11 тестов) и замеры скорости, на .NET 8. Шейдеры собраны компилятором HLSL (с заглушками вместо URP).
- **Показ в браузере:** `WebPreview/` — та же логика и шейдер грунта на WebGL (собирается `node WebPreview/build.mjs`).
- **Не проверено:** код с `MonoBehaviour` (FieldManager, ImplementWorkArea, CropRenderer) и работа шейдеров в самом Unity. Это можно проверить только в редакторе Unity, а его здесь нет.
