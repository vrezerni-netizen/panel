# Шаг 1. Система полей (Field Grid System)

Движок: **Unity 6 (6000.0 LTS), URP, C#**. Код: `Assets/FarmSim/Fields/`.

## 1. Как хранится поле

Как в Farming Simulator, земля не меняет геометрию ландшафта. Состояние каждого кусочка поля лежит в **битовой сетке** («density map»). Шейдер грунта читает эту сетку и рисует пахоту, рядки и стерню.

### Одна клетка = один `uint` (32 бита)

| Биты | Поле | Значения |
|---|---|---|
| 0–3 | Ground | тип грунта: 0 не поле, 1 трава, 2 стерня, 3 культивация, 4 пахота, 5 посев |
| 4–6 | Angle | направление борозд 0..7, шаг 22.5° (180° = полный круг для борозды) |
| 7 | Rolled | прикатано |
| 8–12 | Crop | культура, до 31 вида |
| 13–16 | Growth | стадия роста 0..15 |
| 17–18 | Fert | удобрение 0..3 |
| 19–21 | Weeds | сорняки: 0 нет, 1–3 мелкие, 4–6 крупные, 7 погибли |
| 22 | Lime | известковано |
| 23 | FertNow | в этот период уже удобряли (нельзя удобрить дважды одним проходом) |
| 24–25 | PlowNeed | уборок без вспашки 0..3 (3 = урожай −15%) |
| 26 | Straw | солома или неизмельчённая стерня |
| 27–28 | Stones | камни 0..3 |
| 29–31 | Moisture | влажность 0..7 |

Почему 32 бита, а не 16. В 16 бит помещается только 7 культур, и нет влажности, извести, камней и признака «нужна вспашка». На видеокарте всё равно лежит текстура RGBA32, то есть 4 байта на пиксель, так что 16-битная клетка память там не экономит.

### Память на карту 1×1 км, клетка 0.5 м (2048×2048 = 4,2 млн клеток)

- **Чанки.** Карта делится на чанки 64×64 клетки (32×32 м). Память выделяется только чанкам, где есть поля; в остальных `null`.
- **Состояние клеток** (`uint`, 4 байта): 16 МБ, если вся карта — поля. Обычно поля занимают 30–50%, это 5–8 МБ.
- **Номер поля** (`ushort`, 2 байта): ещё 8 МБ в худшем случае. Нужен для статистики, заданий и наёмных рабочих; в сохранение не попадает.
- **Видеокарта:** одна текстура RGBA32 2048×2048, 16 МБ. На слабых телефонах ставьте клетку 1 м: будет 1024², 4 МБ.

### Измерения

Худший случай: вся карта 1 км² — поля. Мерил на .NET 8 вне Unity, в Unity с IL2CPP цифры того же порядка, с Mono в 2–3 раза медленнее.

| Операция | Время |
|---|---|
| Шаг физики плуга 6 м (0.1 м за шаг) | ~6 мкс |
| Период роста всей карты (4,2 млн клеток) | ~120 мс, разбито по кадрам по 8 чанков: ≈1 мс в кадр, вся карта за ~2 с |
| Сохранение | ~1 МБ (gzip), ~80 мс |
| Статистика одного поля 256×256 м | ~4 мс |

## 2. Связь с шейдером грунта

1. `FieldManager` создаёт текстуру `_FieldStateTex` (RGBA32, Point, без мипов): 1 пиксель — одна клетка, 4 байта — `uint` клетки.
2. **Обновление текстуры.** Изменившиеся чанки помечаются `GpuDirty`. В `LateUpdate` каждый такой чанк, 64×64 клетки или 16 КБ, через маленькую текстуру-посредник копируется в нужное место большой текстуры (`Graphics.CopyTexture`). Вся текстура заново не заливается.
   - Если устройство не умеет `CopyTexture`, включается запасной путь: текстура заливается целиком, но не чаще 10 раз в секунду.
3. Шейдер (`Shaders/FieldGround.hlsl`, узел **Custom Function** в Shader Graph):
   - `FieldGround_float` даёт веса слоёв грунта: трава, стерня, культивация, пахота, посев.
     - Веса смешиваются по 4 соседним клеткам с шумом, поэтому край полосы мягкий, а не «квадратиками».
     - Ещё он отдаёт направление борозд, влажность, удобрение, сорняки и солому.
   - `FieldFurrowUV_float` поворачивает UV текстуры борозд на угол клетки, и борозды идут по ходу трактора.
   - `FieldFurrowNormal_float` поворачивает нормаль обратно в оси ландшафта.
   - `FieldSoilSurface_float` — всё в одном узле: получает текстуры слоёв и карту нормалей борозд, отдаёт Albedo, NormalTS, Smoothness и FieldMask. Проще всего начать с него.
   - В графе albedo, normal и roughness смешиваются по весам. Пахота, культивация и посев получают свою нормаль борозд, по желанию добавляется Parallax Occlusion.
   - Влажность затемняет и делает глянцевее, удобрение даёт лёгкий оттенок.
4. **Растения** (следующий шаг рендера) не создаются через `Instantiate`.
   - Каждый чанк 32×32 м рисуется одним `Graphics.RenderMeshIndirect` на культуру.
   - Вершинный шейдер растения вызывает `FieldCrop_float`: там, где этой культуры нет, вершины сплющиваются в землю; там, где есть, растение масштабируется по стадии роста.

Параметры шейдера глобальные:
- `_FieldStateTex` — сама текстура состояний.
- `_FieldParams` = (originX, originZ, 1/cellSize, cellSize).
- `_FieldSizeCells` = (ширина, высота, 1/ширина, 1/высота).

В Shader Graph эти имена **не** добавлять в Blackboard.

## 3. Проход орудия

`ImplementWorkArea` на орудии. Зона задаётся тремя точками, как в FS:

| Точка | Где |
|---|---|
| `workStart` | левая передняя |
| `workWidth` | правая передняя |
| `workHeight` | левая задняя |

Каждый `FixedUpdate`:

1. **Проверка, работает ли орудие сейчас.** Оно должно быть опущено, ВОМ включён (если нужен), трактор едет вперёд быстрее 0,5 км/ч, а луч вниз показывает, что кромка касается земли.
2. **Направление борозд.** Направление движения переводится в угол борозды 0..7.
3. **Обрабатываемая зона.** `FieldManager.ApplyWorkArea` получает шестиугольник из четырёх треугольников: полосу, которую передняя кромка прошла с прошлого шага, и зону контакта. Поэтому пропусков нет ни на скорости, ни на поворотах.
4. **Изменение клеток.** `FieldGrid.ApplyTriangles` перебирает клетки в рамке зоны. Пустые чанки пропускаются целиком. Для каждой клетки поля, чей центр внутри треугольников, вызывается `FieldOp.TryApply`: это фильтр «можно ли» и изменение битов.
   - Плуг работает только внутри полей.
   - Сеялка сеет только по обработанной земле; по стерне — только при прямом посеве.
   - Жатка убирает только созревшее.
   - Удобрение вносится один раз за период.
5. **Результат.** Возвращается, сколько клеток и квадратных метров обработано и сколько литров собрано. Это пойдёт в расход семян и топлива, в бункер комбайна и в частицы пыли через событие `onWorked`.

Операции: Plow, Cultivate, Sow, Roll, Fertilize, Lime, Weed, Herbicide, Harvest, Mulch, StonePick, Irrigate.

## 4. Рост

- `FieldManager.NextGrowthPeriod(rain)` вызывает система времени, например раз в игровые сутки.
- Расчёт идёт по 8 чанков за кадр, поэтому рывка нет.
- **Что происходит с клеткой за период:**
  - Влажность −1; дождь ставит её на максимум.
  - Культура на стадию дальше, если земля не сухая.
  - При включённом «увядании» созревшее погибает через период.
  - Сорняки появляются на обработанной земле и растут.
  - Флаг «удобрено в этот период» сбрасывается.

## 5. Сохранение

- `FieldGrid.Save()` пишет только чанки с полями, сжатые gzip.
- Номера полей заново строятся из многоугольников `FieldArea`.
- Порядок загрузки: сначала добавить поля, потом `Load`.

## 6. Как собрать в сцене

1. **Менеджер.** Пустой объект → `FieldManager`. Origin — левый нижний угол карты, клетка 0.5 м, размер 2048×2048.
2. **Поле.** Объект → `FieldArea`, номер поля, дочерние пустышки — углы поля по порядку.
3. **Орудие.** На плуг — `ImplementWorkArea`, operation = Plow, три точки рабочей зоны. Свойство `IsLowered` переключает навеска (шаг 2).
4. **Грунт.** Shader Graph (URP Lit):
   - Position (World) → узел Custom Function → File → `FieldGround.hlsl`, функция `FieldSoilSurface`;
   - входы: 5 текстур слоёв, карта нормалей борозд (импорт как Normal map), Tiling 0.25, FurrowSpacing 1.2, EdgeNoise 0.35;
   - выходы Albedo → Base Color, NormalTS → Normal (Tangent), Smoothness → Smoothness.
5. **Тесты.** Window → General → Test Runner → EditMode → Run All. Без Unity: `dotnet test farm-sim/Tools/FieldTests`.

## Что дальше по этой системе

- **Редактор полей в сцене:** рисовать границу мышкой.
